# Licencias Ecosistema Sisma

Control remoto de activacion / desactivacion de los bots.

## Como usar

1. Cada cliente tiene un archivo: `licencia_<CLIENTE_ID>.txt`
2. Contenido del archivo:
   - `activo`   -> el bot funciona
   - `inactivo` -> el bot se cierra al iniciar
3. URL Raw base:
   `https://raw.githubusercontent.com/ANGEL-GALVIS/licencias-sisma/main/`

## Ejemplo

- Archivo: `licencia_ips_cliente_a.txt`
- CLIENTE_ID en el bot: `ips_cliente_a`
